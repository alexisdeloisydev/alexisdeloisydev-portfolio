DELOISY ALEXIS

voici quelques une de mes erreurs les plus mémorables,

j'espere que vous les aprécierez autant que moi :

L'anatomie inversée

Placer la balise <body> après les scripts et les animations. Une structure innovante, mais malheureusement non standard.

Le lien sans fin

Oublier de fermer une balise </a> sur une carte projet, transformant ainsi toute la page en un seul gigantesque bouton cliquable.

L'email fantôme

Laisser Cloudflare obfusquer mon propre email sans m'en rendre compte. Un haut niveau de sécurité, même pour moi-même.

L'exil du bouton

Un position: absolute avec un right: -165px. Le bouton a décidé de prendre ses distances avec le reste du portfolio.

Le mirage de l'IA

Penser que l'IA peut créer un portfolio de A à Z sans intervention humaine. Spoiler : le résultat avait autant de personnalité qu'un grille-pain.

Le commit fantôme

Passer 30 minutes à inspecter l'inspecteur d'élément pour un changement CSS qui n'avait simplement jamais été sauvegardé ou commité.

La mauvaise cible

Modifier avec passion un fichier CSS pendant une heure, pour réaliser que je n'éditais pas le bon fichier.

Le paradoxe lumineux

Créer un logo parfait pour le mode sombre, oublier l'existence du mode clair, et devoir tout recommencer une fois ébloui par le blanc.

L'optimisme du Responsive

Sous-estimer le temps nécessaire pour un CSS propre sur mobile. La deadline est passée, le responsive est resté.
